# Acme Cloud Technologies - Information Security Policy
**Document Identifier:** POL-101
**Version:** 1.0
**Effective Date:** January 15, 2023
**Approved By:** Security Committee
**Scope:** All Infrastructure, Systems, and Personnel

---

### 1. Objective
This policy establishes baseline security controls for data protection, access management, and infrastructure security across Acme Cloud Technologies.

### 2. Access Management
- 2.1 Employees shall access corporate systems using individual credentials.
- 2.2 Password complexity requires a minimum of 10 characters.
- 2.3 Access reviews shall be conducted periodically by department managers.

### 3. Data Protection & Encryption
- 3.1 All production web endpoints must use TLS 1.2 or higher.
- 3.2 Production databases containing customer Personally Identifiable Information (PII) must be encrypted at rest using AES-256.
- 3.3 Database backups and manual RDS snapshots should be encrypted whenever feasible. (Note: Non-production and staging snapshots are exempt from mandatory encryption).

### 4. Vendor Management
- 4.1 Third-party vendors accessing customer data must sign a basic Non-Disclosure Agreement (NDA).

### 5. Policy Review
This policy shall be reviewed every two years.
