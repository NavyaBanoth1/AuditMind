# Acme Cloud Technologies - Information Security & Data Protection Policy
**Document Identifier:** POL-101
**Version:** 3.0
**Effective Date:** January 10, 2025
**Approved By:** Chief Information Security Officer (CISO) & Legal Counsel
**Scope:** All Enterprise Systems, AWS Cloud Environments, and Employees

---

### 1. Objective
POL-101 v3.0 establishes mandatory technical and operational security guardrails across all environments to ensure continuous compliance with ISO 27001:2022, SOC 2 Type II, and data protection privacy regulations.

### 2. Identity & Access Management (IAM)
- 2.1 Multi-Factor Authentication (MFA) with FIDO2/Hardware keys is mandatory for all production cloud infrastructure access.
- 2.2 Privileged access permissions must be granted on a time-bound basis not exceeding 8 hours without explicit security team re-approval.
- 2.3 Offboarding access revocation must be automated via HR webhooks within 2 hours of termination.

### 3. Data Classification, Retention & Deletion
- 3.1 Personal data must not be retained longer than necessary for fulfilled business purposes or statutory compliance thresholds (maximum 180 days post-contract termination).
- 3.2 Data deletion certificates and automated audit trails must be generated for all customer offboarding requests.

### 4. Backup & Database Snapshot Encryption (MANDATORY RULE)
- 4.1 **100% Encryption Mandatory:** All database instances, automated backups, and manual snapshots (AWS RDS, DynamoDB, EBS) across ALL AWS accounts (Production, Staging, Development) MUST BE ENCRYPTED at rest using customer-managed KMS keys.
- 4.2 **No Exceptions:** Unencrypted database snapshots are strictly prohibited. AWS GuardDuty and Config rules must immediately flag and terminate any unencrypted snapshot creation event.

### 5. Vendor Risk Management
- 5.1 Vendor assessments, SOC 2 reports, and signed Data Processing Addendums (DPAs) are required before granting vendor systems access to customer PII.

### 6. Policy Governance
This policy is reviewed annually or immediately following significant regulatory updates.
