# Acme Cloud Technologies - Information Security Policy
**Document Identifier:** POL-101
**Version:** 2.0
**Effective Date:** February 1, 2024
**Approved By:** Chief Information Security Officer (CISO)
**Scope:** All Infrastructure, Systems, and Personnel

---

### 1. Objective
This updated policy aligns Acme Cloud Technologies with ISO/IEC 27001:2022 and SOC 2 Type II trust services criteria.

### 2. Access Management
- 2.1 Multi-Factor Authentication (MFA) is mandatory for all internal and cloud management systems.
- 2.2 Privileged access reviews must occur quarterly and be signed off by the CISO.
- 2.3 Offboarding access revocation must occur within 24 hours of employee separation.

### 3. Data Protection & Encryption
- 3.1 All data in transit across public networks must use TLS 1.2 or TLS 1.3 with strong cipher suites.
- 3.2 All production databases and automated storage volumes must be encrypted at rest.
- 3.3 All manual RDS database snapshots created in production AWS accounts MUST be encrypted using KMS keys. Staging snapshots should be encrypted prior to cross-account transfers.

### 4. Vendor Management
- 4.1 Critical vendors must undergo an annual risk assessment and submit valid SOC 2 Type II or ISO 27001 certificates.

### 5. Policy Review
This policy shall be reviewed annually.
